# Demo Data

All Stage 1 data in `src/modules/demo/fixtures.ts` was authored specifically for this public repository. It was not copied from persisted records, private fixtures, real users, customers, analysts, or unpublished research.

## Fictional Content Policy

- Every fixture carries `fictional: true` and is covered by a persistent global Demo disclosure.
- Names and handles are fabricated for this demo. Handles end in `.demo` and do not represent real social accounts.
- Research uses stable public-demo IDs and slugs, not database identifiers.
- Real ticker symbols appear only inside explicitly illustrative scenarios.
- There are no live prices, price targets, return percentages, subscriber counts, revenue claims, audited outcomes, credentials, wallet addresses, or transaction history.
- Disclosures explicitly reject holdings, sponsorship, compensation, credentials, and performance implications.

The preview-only fixture contains no hidden or paid body. Its public sections are empty by design, so client bundles and route payloads cannot leak a locked demo text.

Interface labels and disclosures are translated. Authored fixture text is identical for English and Turkish to model the rule that creator content is not automatically translated.
